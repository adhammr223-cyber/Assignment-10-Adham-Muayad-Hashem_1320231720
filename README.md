# بطاقات أعضاء فريق

مشروع تعليمي لأدهم مؤيد هاشم، مبني على الكود الحالي بدون إضافة مكتبات أو إطار عمل.

## التقنيات

PHP وHTML وCSS داخل الصفحة.

## ما الذي يقدّمه؟

إنشاء البطاقات من مصفوفة PHP، واستخدام دوال وحلقات وبحث حسب الاسم.

## التشغيل

1. شغّل Apache في XAMPP أو WAMP.
2. ضع مجلد المستودع داخل htdocs أو www.
3. افتح المسار `adham_ass10_project/index.php` عبر عنوان localhost الخاص بالمجلد؛ لا تفتح ملف PHP مباشرة.

## ملفات البداية

- `adham_ass10_project/index.php`

## حدود المشروع

البيانات أمثلة داخل الكود، ولا يحتاج المشروع MySQL.

## مراجعة سريعة

جرّب الصفحة على شاشة هاتف، وتنقّل بلوحة المفاتيح، وتحقق من ظهور الصور وعمل الروابط. يجب تشغيل PHP قبل اختبار الوظائف.
