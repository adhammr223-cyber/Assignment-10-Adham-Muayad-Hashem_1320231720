# PHP Team Directory

A team directory that renders cards from a PHP array and supports searching by name.

## Technologies

PHP, HTML, CSS.

## Run locally

1. Start Apache using XAMPP or WAMP.
2. Place the project in `htdocs` or `www`.
3. Open `adham_ass10_project/index.php` through the corresponding `http://localhost/` URL. PHP files need a PHP server.

## Project scope

The team data is stored in the source code; no MySQL database is required.
